# STM32F103 串口-舵机 透明转发桥

## 架构

```
┌──────────┐     USART1       ┌────────────┐    USART2半双工单线    ┌────────┐
│  PC/上位机 │ ←──────────────→ │ STM32F103C8 │ ←───────────────────→ │ 总线舵机 │
│ (USB-TTL) │  PA10(RX)/PA9(TX) │            │        PA2            │        │
└──────────┘                   └────────────┘                        └────────┘
```

电脑端通过串口助手等工具发送指令，STM32 原封不动转发给舵机；舵机的回应也原封不动回传给电脑。

---

## 接线表

| STM32F103C8T6 | USB-TTL 模块 | 舵机 |
|---------------|-------------|------|
| PA9  (TX)     | RX          | —    |
| PA10 (RX)     | TX          | —    |
| PA2           | —           | 数据线(单总线) |
| GND           | GND         | GND  |

> ⚠️ **三端必须共地！** STM32 的 GND、USB-TTL 模块的 GND、舵机的 GND 要接在一起。

---

## 实物接线示意

### STM32 端

```
        STM32F103C8T6 (最小系统板)
       ┌──────────────────────────────┐
       │                              │
       │  PA9  ──────→ USB-TTL RX     │
       │  PA10 ──────→ USB-TTL TX     │
       │  PA2  ──────→ 舵机数据线      │
       │                              │
       │  GND ─┬───→ USB-TTL GND      │
       │       └───→ 舵机 GND          │
       │                              │
       │  舵机供电: 根据舵机电压要求     │
       │  外接电源(通常5V~8.4V)         │
       └──────────────────────────────┘
```

### USB-TTL 模块端

| USB-TTL 模块 | 连接 |
|-------------|------|
| TXD         | STM32 PA10 |
| RXD         | STM32 PA9  |
| GND         | STM32 GND  |
| VCC (3.3V)  | 可接 STM32 3.3V（仅给模块供电，不要给舵机供电） |

---

## 供电说明

- **STM32 和 USB-TTL 模块**：可通过 USB-TTL 的 3.3V 供电，或 STM32 通过 USB 口供电
- **舵机**：**必须外接独立电源**，不可用 STM32 的 3.3V 或 USB-TTL 供电，电流不够会烧板子
  - 舵机电源正极接舵机供电端
  - 舵机电源负极接 GND（与 STM32 共地）

---

## 波特率

默认波特率 **115200**，8N1（8 数据位 / 无校验 / 1 停止位）。

如舵机波特率不同，修改 `src/main.c` 中 `Servo_Init()` 的参数：

```c
Servo_Init(1000000);  // 例如改为 1Mbps
```

---

## 上位机推荐工具

- **串口助手**（SSCOM、UartAssist、MobaXterm 等）
- 波特率设置 115200 / 8N1
- 直接发送舵机指令（十六进制/文本均可）
- 接收区查看舵机返回数据

---

## 常见总线舵机指令格式参考

以 Feetech 系列总线舵机（SCS/LX 系列）为例：

| 指令 | 十六进制 |
|------|---------|
| 读取角度 | `FF FF 01 04 02 2A 01 D3` |
| 控制舵机 ID=1 转到 500(约90°) | `FF FF 01 07 03 1E 4D 01 F4 01 96` |
| 读取温度 | `FF FF 01 04 02 2B 01 D2` |

具体指令格式请参考你的舵机型号的通信协议手册。

## 编译说明

1. 在 Keil 工程中添加 `HARDWARE/SERVO/servo.c`
2. 添加头文件搜索路径 `HARDWARE/SERVO`
3. 确保 `System/usart/usart.h` 中 `EN_USART1_RX` 为 `0`
4. 编译烧录即可
